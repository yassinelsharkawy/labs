Lab 14: SQL Injection in Product Search Filter

Scenario

An inventory management system provides an endpoint to filter products by category. The category parameter is directly interpolated into a SQL SELECT query via string formatting rather than parameterized placeholders, allowing UNION-based SQL injection to exfiltrate hidden columns such as secret_note.

Objective

Construct a UNION SELECT query payload in the category parameter to extract sensitive internal notes from the database.
