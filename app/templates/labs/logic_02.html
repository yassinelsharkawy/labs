Lab 17: Concurrent Duplicate Refund Processing

Scenario

A merchant billing service allows customers to request refunds on completed purchases. The refund handler reads the order status, issues a wallet credit, and updates the order status to refunded. Because the database operation does not employ row-level locking or an immediate transaction boundary, concurrent requests can claim multiple refund credits for the same single order.

Objective

Initiate concurrent refund requests against a completed order to double-refund the transaction into your wallet.
