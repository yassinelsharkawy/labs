Lab 12: Reflected XSS via Search Redirect Parameter

Scenario

An e-commerce catalog search endpoint accepts a search query q and an optional post-search redirection URL redirect_to. The value of redirect_to is rendered directly into the href attribute of a "Return to Previous Page" link without protocol validation, permitting pseudo-protocols such as javascript:.

Objective

Inject a javascript: payload via the redirect_to parameter and execute arbitrary script when the link is followed.
