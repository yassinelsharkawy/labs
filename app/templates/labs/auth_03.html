Lab 8: Session Persistence After Password Change

Scenario

A web application creates session records when users log in. When a user changes their password, existing sessions for that account should be revoked to prevent continued access from a potentially compromised session. The application fails to invalidate other active sessions.

Objective

Demonstrate that an old session token remains valid after the account's password has been changed.
