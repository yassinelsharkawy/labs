Lab 11: Stored XSS in User Comments Rendered in Admin Panel

Scenario

A platform allows users to post comments on various items. An admin panel renders all comments for moderation. The comment body is stored in the database and rendered in the admin view without output encoding, allowing an attacker to inject JavaScript that executes when an administrator views the comments.

Objective

Post a comment containing a script payload and observe it executing in the admin view.
