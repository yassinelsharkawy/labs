Lab 4: Privilege Escalation via Bulk Role Assignment

Scenario

An organization management platform provides a bulk role-update API for administrators to assign roles and permissions to multiple users at once. The endpoint does not verify that the requesting user has admin privileges.

Objective

As a non-admin user, escalate your own privileges by calling the bulk role-update endpoint to grant yourself admin permissions.

Current Roles

Bulk Role Update

Submit a JSON payload to assign roles. Example:

{"updates": [{"user_id": 2, "role_name": "admin", "permissions": "read,write,delete,manage_users"}]}

API Endpoints

MethodPathDescription
GET/lab/bac/bac-04/rolesList roles in current tenant
POST/lab/bac/bac-04/roles/bulk-updateBulk update roles (JSON body)
