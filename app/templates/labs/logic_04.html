Lab 19: Parallel Verification Token Consumption

Scenario

An onboarding bonus system awards a $10 credit to users upon redeeming an identity verification token. The redemption routine validates that used == 0, credits the user's wallet, and then sets used = 1 in separate non-atomic database commands. In concurrent execution, the single token can be redeemed multiple times before state is committed.

Objective

Simultaneously submit verification requests with the same token to collect multiple onboarding bonuses.
