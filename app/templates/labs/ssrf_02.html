Lab 22: Webhook Tester SSRF to Internal Services

Scenario

A notification integrations hub enables developers to configure and test webhook delivery endpoints. When the "Test Webhook" action is triggered, the server issues an HTTP GET request to the target destination and displays the HTTP response status code and body. The validation fails to restrict private or loopback IP ranges.

Objective

Trigger a webhook delivery test targeting the mock internal administrative configuration endpoint (http://127.0.0.1:5001/internal/admin/config) to retrieve sensitive environment variables.
