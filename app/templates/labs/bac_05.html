Lab 5: Stale Membership Resource Access

Scenario

A collaboration platform grants access to shared team documents based on team membership records. When a user is removed from a team, the membership record is marked inactive rather than deleted. The document access endpoint checks for the existence of a membership record but not whether it is still active.

Objective

Log in as a user who has been removed from a team (carol, user ID 4, removed from Team 1) and access the team's documents through the API.
