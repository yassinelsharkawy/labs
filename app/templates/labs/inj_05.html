Lab 15: Blind SQL Injection in Audit Log Query

Scenario

An administrative compliance audit dashboard allows querying system audit logs by filtering on target usernames. The username parameter is interpolated into an internal sub-query (WHERE user_id = (SELECT id FROM users WHERE username = '...')). Because the sub-query allows boolean injections, an attacker can extract arbitrary database secrets through binary search or character inference.

Objective

Exploit the blind boolean SQL injection vulnerability to verify character-by-character extraction of secret data.
