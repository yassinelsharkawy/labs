Lab 7: Password Reset Token Reuse After Password Change

Scenario

A password-reset flow issues a one-time token via a request endpoint. The token can be used to set a new password. However, when a user changes their password through another means (e.g., the settings page), previously issued reset tokens are not invalidated.

Objective

Request a password reset token, change the password through a separate mechanism, then use the old token to reset the password again.
