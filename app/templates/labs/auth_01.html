Lab 6: MFA Bypass via Legacy API

Scenario

An application has a primary login flow that enforces multi-factor authentication for users who have MFA enabled. A legacy API login endpoint (/api/v1/login) was retained for backward compatibility. This legacy endpoint authenticates credentials but does not enforce the MFA requirement.

Objective

Authenticate as an MFA-enabled user (grace / grace123) through the legacy API endpoint, bypassing MFA verification entirely.
