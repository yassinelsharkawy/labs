Lab 10: OAuth State Parameter Fixation

Scenario

An application implements an OAuth-based account linking flow. The authorization endpoint generates a state token and stores it in the database. The callback endpoint validates that the state token exists but does not verify that it belongs to the current user's session. An attacker can pre-generate a state token and trick a victim into completing the OAuth flow with it.

Objective

Demonstrate that a state token generated by one user can be used in another user's callback, enabling cross-user account linking.
